# Movínea Móveis

Site institucional de uma loja de móveis planejados de Ribeirão Pires - SP.
Projeto acadêmico (PIM) do curso de Análise e Desenvolvimento de Sistemas - Unip EAD.

🔗 Site no ar: https://[seu-usuario].github.io/movinea/

## Páginas
- **Início**: apresentação da loja e diferenciais
- **Projetos**: galeria de trabalhos e etapas do atendimento
- **Orçamento**: dicas, depoimentos e formulário de contato

## Tecnologias
- HTML5 e CSS3
- JavaScript (envio do formulário)
- Google Planilhas + Apps Script (armazena as respostas do formulário)
- GitHub Pages (hospedagem)
